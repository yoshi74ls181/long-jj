# Long Josephson junction simulator

An interactive simulator of the sine-Gordon equation on a long Josephson junction, with per-end boundary conditions and locally adjustable impedance and plasma frequency.

Live at https://yoshi74ls181.github.io/long-jj/

## Share links

Press **Copy link to this state** to get a link that reproduces the simulation as it is at that moment: every setting, the impedance and plasma-frequency profiles, and the phase and voltage along the whole line. Whoever opens the link gets the same state, paused, and presses Run to continue the same simulation.

The state is stored compressed in the part of the URL after `#`, so it is never sent to a server. A link is typically 1–4k characters; a line full of small plasma waves gives longer links than one holding only a few fluxons.
